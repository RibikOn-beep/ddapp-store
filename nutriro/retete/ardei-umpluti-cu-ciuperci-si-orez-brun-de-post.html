Bifează ce ai pregătit. Cantitățile se schimbă cu numărul de porții.

Mod de preparare

  1. Se fierbe orezul brun până este aproape gata.
  2. Se încălzește uleiul de măsline într-o tigaie.
  3. Se adaugă ceapa, morcovul și ciupercile și se gătesc timp de 5-6 minute.
  4. Se adaugă usturoiul și se amestecă.
  5. Se adaugă orezul brun, roșiile, boiaua dulce, sarea și piperul negru.
  6. Se amestecă toate ingredientele timp de câteva minute.
  7. Se umplu ardeii grași cu amestecul obținut.
  8. Se așază ardeii într-o tavă și se adaugă puțină apă.
  9. Se coc la 190°C timp de 35-40 de minute.
  10. Ardeii se servesc calzi.

Etapa 1 – Pregătirea

Se spală ardeii grași, se taie capacele și se îndepărtează semințele. Se spală orezul brun. Se curăță și se toacă ceapa, morcovul, ciupercile și usturoiul. Se taie roșiile.
